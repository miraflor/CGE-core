# GitHub social preview

Phase 2D adds the site-level Open Graph preview automatically through
`docs/_config.yml`.

GitHub's repository-card social preview is configured separately in the
GitHub UI. Upload this committed file:

`docs/_static/cge-core-social-preview.png`

Go to the repository **Settings → General → Social preview → Edit** and upload
that PNG. This step is optional for the website build; it only controls how
the repository itself looks when shared.
