# Provenance notice

This directory is an independently prepared Python/Pyomo replication of the
Cameroon CGE benchmark described in:

- Condon, T., H. Dahl, and S. Devarajan (1987), *Implementing a Computable
  General Equilibrium Model on GAMS: The Cameroon Model*, World Bank DRD290.
- GAMS Model Library example `camcge.gms`, SEQ=81.

No copy of the original paper or `.gms` source file is included in this
directory. The CSV files are a machine-readable transcription of numerical
benchmark tables used for reproducibility. The Python implementation preserves
the model's terminology and equation structure so that its results can be
checked against the published solution.
