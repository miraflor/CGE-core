# Getting Started

CGE-Core is organized around one explicit counterfactual workflow:

**load data → calibrate → shock → solve → compare**

If you are new to the project, use these pages in order:

1. {doc}`../architecture` — see how the data, model equations, workflow engine,
   solver, and validation layers fit together.
2. {doc}`installation` — create an environment and install CGE-Core.
3. {doc}`quickstart` — solve the standard benchmark and one tariff reform.
4. {doc}`first-simulation` — understand what the base and counterfactual
   equilibria mean.

For the older, compact workflow reference, see {doc}`../workflow`.
