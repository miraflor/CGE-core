# IFPRI Validation

The IFPRI subsystem is independently implemented from public mathematical descriptions and is validated against external reference runs.

Validation covers:

- benchmark calibration;
- the BASE solution;
- explicit closure choices;
- five policy simulations; and
- extracted comparison results.

The official IFPRI source package and test data remain external to the repository.

For the detailed workflow and validation procedure, see {doc}`../IFPRI`.
