# CAMCGE Validation

CAMCGE provides a third benchmark family: replication of a published Cameroon
CGE model.

The repository-level replication checks:

- 98 published base-equilibrium variable levels;
- the published objective value; and
- all three published policy experiments.

The reported maximum absolute discrepancy across the 98 compared printed base
levels is approximately $4.98\times10^{-5}$.

This benchmark is kept separate from the installed package because its purpose
is replication and regression testing rather than serving as another installed
core model.

For the full record, see the repository's
[CAMCGE replication guide](https://github.com/miraflor/CGE-core/blob/main/CAMCGE_REPLICATION_GUIDE.md)
and
[CAMCGE validation report](https://github.com/miraflor/CGE-core/blob/main/CAMCGE_VALIDATION_REPORT.md).
