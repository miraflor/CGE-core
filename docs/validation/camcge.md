# CAMCGE Validation

CAMCGE provides a third benchmark family: replication of a published Cameroon CGE model.

The repository-level replication checks the published base equilibrium and policy experiments, including:

- 98 published base-equilibrium variable levels;
- the published objective value; and
- three policy experiments.

This benchmark is deliberately kept separate from the installed package because its purpose is replication and regression testing.

See `CAMCGE_REPLICATION_GUIDE.md` and `CAMCGE_VALIDATION_REPORT.md` in the repository for the full replication record.
